# 🤖 AI Blog Generator

An AI-powered blog generation platform that automatically creates high-quality, SEO-friendly blog content using Large Language Models (LLMs), web research, and content enhancement techniques.

## 🚀 Features

* Generate complete blog articles using AI
* Automated content research
* SEO-friendly blog generation
* Markdown export support
* User-friendly interface
* AI-assisted content improvement
* Fast and scalable content creation

## ⚙️ Installation

### Clone Repository

```bash
https://github.com/sumitpatil27/AI-Blog-Generator.git
cd Blog-Generator
```

### Create Virtual Environment

```bash
python -m venv myenv
```

### Activate Environment

```bash
myenv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure Environment Variables

Create a `.env` file:

```env
GOOGLE_API_KEY=your_google_api_key
TAVILY_API_KEY=your_tavily_api_key
```

### Run Application

```bash
streamlit run frontend.py
```
